SmaxTec Workbench — getting started

INSTALLER BUILD

1. Open SmaxTec Workbench from the Start menu or desktop shortcut.
2. Windows Settings > Apps > Installed apps contains the uninstall option.
3. Installing a newer version over the existing version keeps the same application
   identity and updates its bundled program files.

PORTABLE PREVIEW BUILD

Extract the complete ZIP, keep the _internal folder beside SmaxTec Workbench.exe,
and open the executable. Do not move the executable out of that folder.

DIRECT DATA API — RECOMMENDED WORKFLOW

1. Enter your authorized smaXtec email and password, then choose Connect.
2. Choose a farm and select cows by clicking rows, selecting filtered rows, or pasting
   exact animal numbers. Animal numbers are matched exactly.
3. Enter each target's From, To and optional Study T0. Shared T0/date actions are
   explicit conveniences; every queue row remains independently editable.
4. Add targets to the queue. In Download queue, select one, several or every row and
   assign the measurements required for those targets.
5. Choose Native, 10-minute, hourly or daily resolution, configure the aligned-data
   window, output location/name and optional Excel output.
6. Review every target, period, T0 and measurement before confirming the download.
7. Open the saved collection or outputs from Results.

Every completed collection preserves raw API JSON, collection.json lineage, the
technical measurements.csv and graph-ready analysis_ready.csv. Optional output.xlsx
is descriptive. Cow collections with the required metrics also create
client-analysis.xlsx with Cow analysis and Aligned data sheets. Native timepoints keep
exact-timestamp behavior. Aggregated reports use their bounded API buckets; daily data
cannot recreate six-hour activity windows, so daily activity fields are labelled
proxies. Client acceptance is still required before clinical interpretation.

If API lifecycle data does not provide Lact/DIM, Results can add current website
diagram values to a new, non-overwriting analysis workbook. They are scrape-time
snapshots, not historical T0 values.

ACCOUNT AND DATA NOTES

- smaXtec credentials and bearer tokens are held in memory for the connected session
  and are not written to the collection folder.
- Choose Disconnect or close the application when finished.
- Save output to an approved user or organisation folder, not the installation folder.
- The Legacy website + email workspace remains a compatibility route. Microsoft 365
  access can require organisation approval; the application does not bypass policy.
- This is an independent integration project, not an official smaXtec application.

SUPPORT INFORMATION TO RECORD

When reporting a problem, provide the Workbench version, Windows version, the operation
being attempted and the user-facing error text. Do not send passwords, bearer links,
tokens, raw farm data or authenticated screenshots unless an approved support process
explicitly requests and protects them.
