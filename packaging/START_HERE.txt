SmaxTec Workbench — desktop preview 0.10.0

1. Extract the complete ZIP into a folder on your computer.
2. Open SmaxTec Workbench.exe. Keep the _internal folder beside it.
3. In Direct data API, enter your smaXtec email/password and choose Connect.
4. Choose a farm. Click rows to toggle cows without holding Ctrl, select every filtered
   row, or paste exact cow numbers separated by commas, spaces or new lines.
5. Enter From and To as DD/MM/YYYY and add the selected targets to the queue.
6. Repeat for other farms, targets or periods. Every queue row keeps its own dates.
7. Open Download queue and select one, several or every queued row. Use all available
   measurements, or find the codes common to the selected targets, check the ones you
   need and apply them only to those selected rows.
8. Edit individual dates. If this is a cow treatment/key-event study, optionally enter
   that cow's Study T0 as DD/MM/YYYY HH:MM in the farm's timezone. Then choose
   resolution, optional weekly farm health index, output folder/name and optional Excel.
9. Choose Review & download. Inspect every target/date/measurement row, then confirm.
10. Results shows each saved, partial, failed or cancelled target. Open the graph-ready
    CSV, presentation workbook, automatic client analysis or complete audit folder
    directly from that screen.
11. Choose Disconnect or close the app to release the in-memory API session.

AUTOMATIC CLIENT ANALYSIS AND GUIDED STUDY PREVIEW

Completed cow collections with usable measurements also create client-analysis.xlsx
automatically. It follows the client's one-row-per-cow T/AT/RT order and includes
normal values, an Analysis summary, aligned cow sheets, graphs, Definitions and QC.
The automatic mapping uses exact source codes found in a saved collection:
temp_normal_index/degree_celsius (normal-temperature interpretation pending client
confirmation), temp_without_drink_cycles/degree_celsius for T, act/act and
rum_index/seconds. Rumination is shown in minutes in this derived workbook, while
the raw CSV remains seconds. If Study T0 is blank, exact measurements are aligned
around that cow's From date at farm-local 00:00, labelled a PERIOD ANCHOR, not a
treatment time. Enter actual T0 for treatment studies; baseline/follow-up fields
may be blank if outside the collected range.

In Results choose Create study workbook, or Choose saved collection for an earlier
complete API collection. Match the source codes/units for normal temperature,
temperature without drinking cycles, activity and rumination. An unavailable role
may stay unmapped; its fields will be blank. Enter the actual event/treatment time
for every cow as DD/MM/YYYY HH:MM in that farm's timezone. Optionally copy a truly
shared time with Apply to every cow, then review the whole table. Choose study
windows and create. A separate client-study.xlsx appears beside the original
collection. Its first sheet has one cow/case per row; aligned cow sheets, cohort
graphs, Definitions and QC follow. T6 means an actual point exactly six elapsed
hours after time zero; missing exact data stays blank. Talert/R20 are labelled
proxies and Lact/DIM/Rback remain blank. This analytical preview needs client
acceptance before clinical interpretation.

Each run makes a unique folder with raw API JSON, the unchanged technical
measurements.csv, an easier graph-ready analysis_ready.csv, optional XLSX and a hashed
collection.json manifest. Start with analysis_ready.csv for filtering and future charts.
The Excel file opens with a collection overview, observation-count chart, measurement
index and data guide; its source-data sheets retain every technical column. Use
measurements.csv/raw JSON when auditing the source. Earlier collections are never overwritten.
Credentials and bearer token stay in memory and are not written to that folder.

No Python, editor, browser driver or package installation is required.

LEGACY WEBSITE & EMAIL

The Legacy website + email tab retains the earlier browser export and mailbox routes
while direct API client acceptance is completed. Use it only when direct API data cannot
supply the required result. Microsoft 365 mailbox sign-in may require an organization-
approved app registration; classic Outlook and saved .eml/.msg import remain fallbacks.
Emails are not marked read, moved or deleted. Existing labels remain unchanged.

This is an unsigned development preview. Direct downloads, date boundaries, units and
output still require representative client acceptance. The production release will have
an installer and clean standard-user-machine verification. Do not move the executable
out of its extracted folder.

This application is an independent integration project, not an official smaXtec app.
